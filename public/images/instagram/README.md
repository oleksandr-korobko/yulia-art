# Instagram Images

## Required Files

Place 8 Instagram post images in this directory:

- `instagram-1.jpg` - Installation artwork detail
- `instagram-2.jpg` - Ceramic sculpture in progress
- `instagram-3.jpg` - Material-based painting close-up
- `instagram-4.jpg` - Archival work with text elements
- `instagram-5.jpg` - Studio workspace view
- `instagram-6.jpg` - Sculptural installation piece
- `instagram-7.jpg` - Ceramic forms arrangement
- `instagram-8.jpg` - Exhibition installation view

## Image Specifications

- **Format**: JPG (preferred) or PNG
- **Size**: 1200x1200px (square, Instagram-style)
- **Quality**: High quality, optimized for web
- **File size**: < 500KB per image

## How to Add Images

1. Export 8 recent Instagram posts from your account (@yuliia_art_uk_ua)
2. Rename them to `instagram-1.jpg` through `instagram-8.jpg`
3. Place them in this directory
4. Update the Instagram post IDs in `content/pages/about.md` to match real posts
5. Commit and redeploy
